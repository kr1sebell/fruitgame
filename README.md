# Orange Paradise ферма

Одностраничная браузерная игра, в которой вы управляете цитрусовыми плантациями. Состояние сохраняется в `localStorage`, поэтому ферма продолжает работать между сессиями.

## Запуск

1. Откройте файл [`index.html`](index.html) в современном браузере.
2. Разрешите хранение данных в `localStorage`, чтобы прогресс сохранялся автоматически.

## Основные возможности

- Личный кабинет с балансом игрока, уровнями участка и склада.
- Несколько участков с возможностью расширения и покупки новых.
- Деревья с уровнями развития, ручным и автоматическим поливом и сбором урожая.
- Два прогресс-бара на каждое дерево: влажность (уменьшается) и созревание (увеличивается).
- Склад с контролем заполнения, продажей и переработкой продукции.
- Автоуслуги (полив/сбор) с ежедневным списанием средств и автоматическим отключением при нехватке валюты.

## Структура проекта

```
.
├── index.html         # Разметка и шаблоны интерфейса
├── css/
│   └── styles.css     # Стили и оформление
└── js/
    ├── config.js      # Конфигурация, базовые коэффициенты и форматирование
    ├── storage.js     # Обёртка над localStorage
    ├── models.js      # Игровые сущности (игрок, склад, участки, деревья)
    ├── game.js        # Логика, таймеры и изменение состояния
    └── ui.js          # Рендеринг интерфейса и обработка действий
```

## Полезные заметки

- Один игровой день в демо равен 10 минутам реального времени, чтобы можно было увидеть прогресс во время теста.
- Автополив и автосбор можно включить как на уровне участка, так и отдельно для дерева. Стоимость услуги указана во всплывающих подсказках.
- При нехватке места на складе или валюты отображаются уведомления в правом нижнем углу.
- Для отладки в консоли доступен объект `window.orangeParadise.game`.
