# Fruit Dominion

Изометрическая браузерная ферма на Phaser 3. Игра запускается прямо из файла `index.html` и сохраняет прогресс в `localStorage`.

## Как запустить

1. Откройте `index.html` в современном браузере (Chrome, Firefox, Edge).
2. Управляйте фермерским хозяйством через интерфейс поверх игрового поля и перемещение камеры.

### Управление камерой

- **WASD / стрелки** — перемещение камеры по карте.
- **ПКМ / колесико мыши** — зажатие правой кнопки или средней кнопкой перетаскивает камеру.
- **Колёсико мыши** — приближение и отдаление.

## Основные возможности

- Изометрическая карта с участками, деревьями, складом и заводом.
- Рост деревьев с уровнями, сбор урожая, автополив и автосбор.
- Склад с ухудшением урожая со временем, продажа и переработка продукции.
- Завод, создающий переработанные товары из урожая.
- Улучшение участков, склада и расширение фермы за игровую валюту.
- Debug Mode с отображением FPS, объектов, баланса и ускорением времени.
- Полноэкранный Phaser-интерфейс с панелями, всплывающими уведомлениями и настройками.

Прогресс автоматически сохраняется каждые несколько секунд и при закрытии вкладки.
